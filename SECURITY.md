## Reporting a Vulnerability

If you discover a potential security vulnerability, financial exploit, or denial-of-service vector in `agent-intent-settlement`, please do not report it in public GitHub issues.

Instead, please report security vulnerabilities directly to the maintainer:
- Maintainer: Lakshitha Dananjaya (devsoniclk)
- Email: dananjayarox01@gmail.com

We review and address valid security disclosures within 48 hours.
